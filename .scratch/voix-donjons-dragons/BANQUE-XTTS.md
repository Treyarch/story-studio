# Banque XTTS par personnage

Qualité des échantillons globalement approuvée par l’utilisateur. Les variantes ci-dessous sont choisies selon une règle explicite : original si le fond estimé est inférieur ou égal à −20 dB ; sinon variante UVR si disponible, puis Spleeter. Ce choix automatique reste modifiable après comparaison.

Chaque personnage possède un seul identifiant XTTS. Les extraits de plusieurs scènes sont transmis comme références séparées, sans concaténation. Les narrations des deux histoires restent deux profils ; les rapprochements acoustiques seuls ne créent pas de fusion.
