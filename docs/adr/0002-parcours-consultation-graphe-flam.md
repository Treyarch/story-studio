# Construire les parcours de consultation dans le graphe FLAM

Les références visuelles de l’auteur mêlent menus, inventaire et fiches consultables,
alors que le cadrage précédent réservait le graphe au scénario et configurait les
rubriques à part. Le graphe représentera aussi les parcours de consultation afin
que l’auteur puisse construire leurs liens visuellement ; ces parcours conservent
leur navigation indépendante du récit et permettent de retrouver la scène narrative
sans rejouer ses effets ni perdre la progression.

Cette décision révise la séparation d’édition décrite dans le
[cadrage du menu illustré](../../.scratch/flam-interface-aventure/spec.md).
Elle conserve la distinction entre consultation et progression narrative ;
elle ne fixe pas encore les types d’écrans ni les règles de leurs liens.
